01Nœuds de rendu (musique + vidéo)

Les vidéos partent sur le meilleur nœud libre : PC avec NVIDIA (NVENC) d’abord, puis Mac Apple Silicon (VideoToolbox), puis libx264, puis le CT en secours. Si un nœud tombe pendant un rendu, la vidéo repart sur un autre nœud ou sur le CT. Depuis la v1.16.0, un agent 1.16+ rend aussi la musique (même moteur que le CT, identique au bit près) ; la v1.18.0 ajoute le Mac mini (VideoToolbox).

02Répartition

Toutes les vidéos vont sur ce nœud. S’il est hors ligne, le CT prend le relais.
min
Option « Faire la musique et la vidéo en même temps sur le PC / Mac » (formulaire Générer) : quelle que soit la durée, la musique est rendue sur le nœud (PC Windows NVIDIA ou Mac Apple Silicon) puis la vidéo longue y est encodée aussitôt, sans attendre le CT ; le ZIP unique (vidéo, mix MP3 + WAV, morceaux, MIDI, samples) est prêt à télécharger à la fin. Si le nœud tombe, le CT reprend (musique ou vidéo) et le statut le dit.

03PC IA (Ollama)

Directeur artistique et, en repli, veille tendances. Sans PC joignable : propositions locales.

Directeur artistique

Veille tendances (modèle dédié)

URL optionnelle (sinon celle du directeur). Modèle propre recommandé. Si le modèle veille est vide : repli sur le modèle directeur, avec avis visible.

04Veille tendances

—

Crawl autonome de métadonnées publiques (RSS, pages), résumé par le modèle veille, propositions de retouches. Rien n’est appliqué tout seul : bouton « Appliquer » par proposition. Pas de téléchargement audio, pas de connexion à des comptes.

05Chaînes YouTube

—

Une chaîne par style (une chaîne peut servir plusieurs styles) ; la chaîne par défaut sert aux styles sans liaison. Pas de connexion Google depuis le navigateur : colle le client ID, le client secret et le jeton d’actualisation obtenus une fois (voir docs/YOUTUBE.md). Les secrets sont enregistrés sur le CT (fichier lisible par soundtube seul), jamais réaffichés ni journalisés.

Champ secret laissé vide = valeur enregistrée inchangée.

06Animations

—

Bibliothèque des fonds animés des vidéos (MP4, WebM, MOV, GIF, PNG, JPG). Chaque animation importée apparaît dans le formulaire de génération (Créer → Avancé → « Animation de la vidéo ») et dans le panneau YouTube de chaque morceau.

07Contexte du directeur artistique

—

Deux sources facultatives ajoutées au prompt du directeur artistique (Créer → « Décris l’ambiance »). Chacune a son interrupteur ; coupées, le prompt est exactement celui de la v1.14. Les noms d’artistes servent seulement à orienter le son : ils sont interdits et retirés des titres, descriptions et tags proposés.
