un morceau.

soundtube est un studio qui tourne sur ton serveur (le CT). Il compose, joue et masterise ; un PC Windows peut faire les vidéos et un PC IA peut jouer le directeur artistique. Voici le circuit, puis une visite en cinq étapes.

01Le système

toiNavigateur

Studio, pages de style, Admin. Réseau local seulement, jeton facultatif.

serveur · CTsoundtube
  1. Théorie gamme, mode, progression tirés de la graine
  2. Composition mélodie (Markov), basse, batterie, forme
  3. Synthèse machines recréées en JavaScript
  4. Mix & master sidechain, bande, −14 LUFS
  5. Fichiers WAV · MP3 · MIDI · vidéo YouTube
facultatifPC IA (Ollama)

« Décris l’ambiance » → réglages validés par le serveur. Veille tendances hebdomadaire. Sans lui : propositions locales.

facultatifPC Windows

Agent de rendu vidéo (NVENC / x264) ; sinon le CT fait la vidéo lui-même.

02Visite en cinq étapes

Flèches ← → du clavier pour naviguer.

    03Premiers réglages

    Une fois pour toutes.
    1. Nom de la chaîne affiché sur les miniatures et les vidéos : studio → bibliothèque → panneau YouTube d’un morceau.
    2. PC IA (Admin → PC IA) : adresse Ollama (ex. http://192.0.2.10:8080/proxy/ollama), modèle qwen3:14b, délai, puis « Tester la connexion ».
    3. PC Windows (facultatif, Admin → Nœuds de rendu vidéo) : « Rechercher sur le réseau » trouve l’agent installé.
    4. Veille tendances (Admin) : clé YouTube Data API ou flux RSS, fréquence, styles suivis.
